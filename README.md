## 📌 About the Project

**Augmented Horizons: New Realities in Education** is an Augmented Reality (AR) project designed to enhance learning through interactive 3D visualization. By combining real-world image markers with virtual 3D models, the application provides an immersive way to explore digital content in a physical environment.

Built using Unity 3D, C#, and Google ARCore, the project demonstrates how marker-based image tracking can make educational content more interactive and engaging.

## 🎯 Objectives

- Develop an interactive mobile AR learning experience.
- Detect predefined image markers using image tracking.
- Display corresponding 3D models in the real-world camera view.
- Improve visualization of digital learning materials.
- Support an offline marker-to-model workflow.

## ✨ Key Features

- **Image-Based Tracking:** Recognizes predefined visual markers.
- **3D Model Visualization:** Displays virtual objects associated with tracked images.
- **Interactive AR Experience:** Combines camera input with digital content.
- **Mobile Deployment:** Designed for compatible Android devices.
- **Offline Workflow:** Supports marker-to-model experiences without requiring continuous internet connectivity, where configured.

## ⚙️ How It Works

1. Launch the application on a compatible Android device.
2. Point the device camera at a supported image marker.
3. The AR tracking system detects and tracks the marker.
4. The application associates the tracked image with its configured 3D model.
5. The virtual model appears in the camera view, creating an augmented reality experience.

## 🚀 Getting Started

### Prerequisites

- Unity 3D with a compatible ARCore setup.
- Android SDK and required build tools.
- An ARCore-supported Android device.
- C# development support in Unity.
- The project's image marker reference assets and 3D models.

### Setup Instructions

1. Clone or download this repository.
2. Open the project using a compatible Unity version.
3. Import or verify the required ARCore/AR Foundation packages used by the project.
4. Configure the image tracking reference library and associated 3D models.
5. Set the appropriate Android build settings.
6. Connect a compatible Android device and build and run the application.

> **Note:** Exact Unity versions, package dependencies, and build settings depend on the original project configuration.
